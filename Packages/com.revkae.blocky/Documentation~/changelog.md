# Changelog

Every release of Blocky — what was added, what changed and what was fixed — is recorded in `CHANGELOG.md`, in the package's root folder next to `package.json`. In the Unity Editor you find it under *Packages › Blocky* in the Project window.

The same file is online at [github.com/revkae/Blocky](https://github.com/revkae/Blocky/blob/main/Packages/com.revkae.blocky/CHANGELOG.md).

The changelog follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).
